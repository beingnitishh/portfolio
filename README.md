# Nitish Kumar — portfolio

Personal site for **Nitish Kumar**, E-Commerce Executive & AI Tools Specialist.

**Live:** [https://beingnitish.me](https://beingnitish.me)

## What this is

A Next.js App Router portfolio covering marketplace operations (Shopify, Flipkart, Meesho), applied AI tooling, and the products built around that work — including [SellerMetric](https://sellermetric.vercel.app/).

## Stack

Next.js · React · TypeScript · Tailwind CSS · Framer Motion · Canvas sequence hero

## Develop

```bash
npm install
npm run dev
```

```bash
npm run build
```

## Notable routes

- `/` — homepage
- `/projects` — case studies
- `/projects/sellermetric`
- `/writing`
